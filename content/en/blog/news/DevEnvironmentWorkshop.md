# Ready to Build? Join the Ortelius Developer Workshop!

**Help shape the future of Ortelius! We're making it easier for developers to get involved, make front-end improvements, and build Ortelius locally.**

The Ortelius open-source community is growing, and we want to make it easier for more developers to jump in and contribute. One of the biggest hurdles to contributing to any open-source project is getting a working development environment set up. We're tackling that challenge head-on with a hands-on developer workshop!

On **Friday, November 20, 2026, at 8:00 AM ET**, **Steve Taylor** will lead a community workshop focused on helping developers configure their local environments, build Ortelius, and get ready to make changes to the Ortelius front-end.

## Let's Get More Developers Building Ortelius!

Our goal is simple: **Get more developers comfortable working with the Ortelius codebase so they can start making real contributions.**

We're particularly interested in growing the community of developers who can work on the Ortelius front-end. Whether it's improving the user experience, updating interfaces, fixing bugs, or adding new features, there's plenty of opportunity to make an impact.

During the workshop, we'll focus on:

- **Setting up a local development environment** using VS Code and the Ortelius developer resources.
- **Building Ortelius locally** so contributors can work with and test the application.
- **Getting ready for front-end development** by understanding how to configure the environment and begin making changes.
- **Troubleshooting setup challenges** so more developers can get past the initial hurdles and start contributing.

The objective isn't just to get Ortelius running on your laptop. It's to give developers the foundation they need to make changes, test their work, and eventually submit pull requests.

## Meet Your Workshop Leader: Steve Taylor

Steve Taylor will guide participants through the developer setup process, sharing practical tips and helping troubleshoot common challenges.

This will be a hands-on session, so bring your laptop, follow along, and ask questions. New contributors are especially welcome!

## Get a Head Start Before the Workshop

We encourage everyone to review the following documentation before joining. You don't need to have everything working perfectly. In fact, discovering where developers run into trouble will help us improve the onboarding experience for future contributors.

1. **[Developer Resources](https://docs.ortelius.io/guides/contributorguide/developer-resouces/)** – Start here for developer resources and setup guidance.
2. **[VS Code Backend Setup](https://docs.ortelius.io/guides/contributorguide/front-end-development/vscode-backend-setup/)** – Prepare your backend environment.
3. **[VS Code Setup](https://docs.ortelius.io/guides/contributorguide/front-end-development/vscode-setup/)** – Configure your local development tools.
4. **[Application Build and Containerisation](https://docs.ortelius.io/guides/contributorguide/application-build-and-containerisation/)** – Learn how to build and run Ortelius locally.
